# Doggy Engine v1.0

Doggy is a client-side layout rendering library built to turn raw text strings into a clean, modern documentation manual. It automatically parses explicit custom phrase properties, handles dark mode color theme synchronization, scales gracefully to mobile/tablet screen viewports, and structures navigation frameworks inside the browser memory.

## Universal Usage Guide (Beyond Doctor)

While Doggy is designed to seamlessly parse explicit phrase shortcuts, it can process and format **any raw text container** injected onto a webpage. 

If you are building a custom frontend web interface and want to utilize Doggy's responsive column typography, clean layout arrays, and structured side menus, simply load it at the top of your HTML text framework:

```html
<script src="https://jsdelivr.net"></script>

<!-- The engine parses the raw textual values found inside the document body -->
title# My Universal System Manual

bar# Category One
page# Section Header Name
Your custom text guidelines and content parameters go right here.
```

## Core Processing Parameters

The layout block parsing loops scan the text stream for explicit keyword phrases followed directly by a single hashtag (`#`) token:

* `title#` Dictates the primary project logo string at the top header of the side menu.
* `bar#` Automatically splits content categories and spins them up as clickable sidebar selection links.
* `page#` Formats the dominant bold title heading at the very top of the selected view tab panel.
* `header#` Generates clean sub-headings directly within your paragraph text fields to organize information.
